# CA1 – P4 Learning Switch (Phase 1)

Phase 1 of the course project with **Amirhossein Mansouri**. We set up a full P4 development environment (the BMv2 software switch in Mininet, on a VM hosted on Windows) and worked towards a **layer-2 learning switch** written in P4. Most of this phase was solving the toolchain and virtualisation problems. The report documents the whole setup process and our test topology.
